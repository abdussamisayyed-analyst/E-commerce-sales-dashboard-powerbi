# E-Commerce Sales & Analysis Dashboard

## 📌 Project Overview
This project is an interactive E-Commerce Sales & Analysis Dashboard developed using Power BI. The dashboard provides valuable business insights related to sales performance, profit trends, customer behavior, product categories, and payment methods.

The main objective of this project is to analyze e-commerce business data and help stakeholders make data-driven decisions using visual analytics.

---

## 📊 Dashboard Features

### 🔹 KPI Metrics
- Total Sales Amount
- Total Profit
- Total Quantity Sold
- Average Order Value (AOV)

### 🔹 Sales Analysis
- State-wise sales performance
- Customer-wise sales contribution
- Category and sub-category analysis
- Monthly profit trends

### 🔹 Payment Analysis
- Payment mode distribution
- COD, UPI, Debit Card, EMI analysis

### 🔹 Interactive Filters
- Quarter-wise filtering
- State-wise filtering
- Dynamic visual interaction

---

## 📂 Dataset Information
The project uses two datasets:

1. Orders.csv  
2. Details.csv  

The datasets contain:
- Order details
- Customer information
- Product categories
- Sales amount
- Profit
- Quantity
- Payment modes

---

## 📈 Key Insights
- Maharashtra generated the highest sales revenue.
- Clothing category contributed the largest quantity of sales.
- Printers produced the highest profit among sub-categories.
- COD was the most used payment method.
- Profit fluctuated across different months with highest profit in December.
